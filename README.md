# בחירת גנרטור — משרד טיקטין חשמל

אפליקציה ציבורית, מהירה וללא שמירת מידע לבחירת גנרטור לפי KVA. מציגה מידות ומשקל גנרטור, חדר מושתק, פתחי אוויר וחופות אקוסטיות 65dB ו־75dB, עם העתקה, מייל והדפסה.

הנתונים מבוססים על הסרגל והעמודים הרשמיים של חברת שמרלינג. יש לאמת את הנתונים והתוכניות מול שמרלינג לפני תכנון או ביצוע.

האתר הציבורי: https://tiktiny.github.io/tiktin-generator-selector/

## קובצי תוכניות

המאגר מוריד ושומר את קובצי המקור הרשמיים בתוך האתר. קובצי DXF נוצרים מגאומטריה וקטורית בעמוד הראשון של ה־PDF. קובצי DWG נוצרים בפורמט R2000 ומוצגים באפליקציה רק לאחר בדיקת מבנה והמרה חוזרת תקינה; עדיין נדרשת בדיקת קנה מידה ותוכן בתוכנת CAD לפני שימוש מקצועי.

פותח ע״י יובל טיקטין בסיוע AI.
